# Laboratorio de Análisis de Datos con NumPy

## Descripción

Este proyecto corresponde a la Actividad de Aprendizaje No. 3 del programa ADSO del SENA.

El objetivo es desarrollar diez ejercicios independientes utilizando exclusivamente la biblioteca NumPy para resolver diferentes problemas de análisis de datos.

## Tecnologías utilizadas

- Python 3
- NumPy
- Git
- GitHub
- Visual Studio Code

## Estructura del proyecto

```
laboratorio-numpy-sena
│
├── ejercicios
├── documentacion
├── investigacion
├── recursos
├── README.md
├── requirements.txt
└── main.py
```

## Instalación

Clonar el repositorio

```bash
git clone URL_DEL_REPOSITORIO
```

Crear el entorno virtual

```bash
python -m venv .venv
```

Activarlo

Windows

```bash
.venv\Scripts\activate
```

Instalar dependencias

```bash
pip install -r requirements.txt
```
