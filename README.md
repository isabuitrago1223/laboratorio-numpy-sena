## Descripción

Este proyecto corresponde al **Laboratorio de Análisis de Datos con NumPy**, desarrollado como evidencia de aprendizaje del programa **Análisis y Desarrollo de Software (ADSO)** del **Servicio Nacional de Aprendizaje (SENA)**.

El laboratorio tiene como propósito aplicar las principales funciones de la biblioteca **NumPy** mediante ejercicios prácticos relacionados con el análisis de datos, arreglos, matrices y operaciones estadísticas.

---

#  Objetivo General

Desarrollar diferentes ejercicios utilizando la biblioteca NumPy para fortalecer los conocimientos sobre el manejo de arreglos, matrices y análisis de datos en Python.

---

#  Objetivos Específicos

- Utilizar la biblioteca NumPy.
- Crear y manipular arreglos y matrices.
- Aplicar funciones estadísticas.
- Resolver problemas mediante programación.
- Implementar un menú para ejecutar los ejercicios.
- Documentar el desarrollo del proyecto.
- Aplicar control de versiones con Git y GitHub.

#  Instalación

## 1. Clonar el repositorio

```bash
git clone https://github.com/isabuitrago1223/laboratorio-numpy-sena.git
```

## 2. Ingresar al proyecto

```bash
cd laboratorio-numpy-sena
```

## 3. Crear el entorno virtual

```bash
python -m venv .venv
```

## 4. Activar el entorno virtual

### Windows

```bash
.venv\Scripts\activate
```

### Git Bash

```bash
source .venv/Scripts/activate
```

## 5. Instalar las dependencias

```bash
pip install -r requirements.txt
```
